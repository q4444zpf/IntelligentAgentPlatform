# 成果文件页面实施计划

**目标：** 将“成果文件”导航接入真实 Artifact API，展示当前用户可见成果并提供预签名下载。

**方案：** 新增 `artifactsApi` 封装 `/api/artifacts` 和下载接口；新增专用 `ArtifactListView.vue`，采用现有运行审计页的表格、刷新、错误和空状态模式；将 `/artifacts` 路由从静态通用模块切换到该视图。下载只打开后端返回的短期预签名 URL，不在前端保存对象存储凭据。

## 验收

- 列表请求失败显示重试入口。
- 成果文件名、Run ID、类型、大小、创建时间和状态可见。
- 下载按钮获取预签名 URL 并在新窗口打开。
- `/artifacts` 页面不显示“系统集成”。
- API、组件测试和生产构建通过。
