# 通用智能体平台前端

前端使用 Vue 3、TypeScript、Vite 和 Ant Design Vue 实现，并按 Vue Vben Admin 的典型思路组织路由、菜单、权限、布局和业务模块。当前 AI 对话、Agent 管理、MCP、Skill / Tool、大模型配置、平台总览和 `/runs` 已接入对应后端 API；资源库、Prompt、知识库、流程编排、多智能体协同、系统管理和沙箱等页面仍包含 Mock 数据或静态原型。

当前仓库原本没有现成 Vue Vben Admin 工程，因此本目录提供可运行的前端应用骨架；各页面是否接入真实 API 以上述实现边界和实际代码为准。

## 运行命令

```bash
npm install
npm run dev
npm run build
```

默认开发地址：

```text
http://localhost:5173
```

## 当前能力

- Vue Router 路由
- 菜单配置
- 权限码 Mock
- Ant Design Vue 企业级 UI
- 部分资源、业务编排、系统管理和沙箱页面使用 Mock 数据或静态展示
- AI 对话、Agent、MCP、Skill / Tool、大模型供应商和平台总览调用后端 API
- 通用管理列表页
- 沙箱执行状态展示
- `/runs` 展示当前项目、当前用户范围内的真实 Agent Run，支持状态、智能体、关键字、日期筛选和服务端分页。
- 运行详情在打开抽屉时按需加载基础信息、有限事件时间线和工具调用安全摘要；三个区域可独立重试，越权或不存在的资源统一显示安全的 404 提示。
- 列表和详情仅由首次进入、用户操作或手动刷新触发请求，不进行自动轮询；手动刷新会清理详情缓存并重新读取当前数据。

## 审计范围演进

`/runs` 保持 Agent 运行专项审计。后续规划在 `/system/audit` 扩展 Agent、MCP、知识库、沙箱和模型调用的统一审计；该统一审计当前尚未实现。
